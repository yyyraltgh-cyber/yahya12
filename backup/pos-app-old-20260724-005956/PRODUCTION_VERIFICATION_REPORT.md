## Bugs found and fixed during verification

1. **Auth confirmation redirect (critical).** Signup sent the email
   confirmation link straight to `/dashboard`, so the Supabase `code` was never
   exchanged for a session and the user bounced back to login. **Fixed:** now
   redirects through `/auth/callback?next=/dashboard`, which exchanges the code
   then forwards. Also added `window.location.origin` fallback.

2. **Notes missing Update (feature gap).** Notes had create/read/delete but no
   edit. **Fixed:** added inline edit UI + `.update()` mutation → full CRUD.

3. **Non-responsive navigation (mobile UX).** The sidebar was a fixed 224px rail
   that would consume most of a phone screen. **Fixed:** hidden on mobile,
   replaced by a fixed bottom nav; content areas got `pb-24 sm:pb-6` clearance.
